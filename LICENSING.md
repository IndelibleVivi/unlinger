# Licensing

Unlinger is **source-available**, not OSI open source. Faye Fang selected these scopes on 2026-09-08 for project-original material under her control. Repository visibility, software licensing and a packaged App release are separate facts.

| Material | Governing terms |
| --- | --- |
| Rust and Swift source/tests, shell/Python scripts, build and CI configuration, package manifests/lockfiles, TOML rule packs, functional JSON fixtures/schemas/support matrix | [Sustainable Use License 1.0](LICENSE), SPDX `SUL-1.0` |
| Prose documentation throughout the tree, including READMEs and agent/operator guides | [CC BY-NC-SA 4.0](LICENSE-DOCUMENTATION.md) |
| Architecture diagram source and rendered export (`docs/architecture.mmd`, `docs/architecture.svg`) | [CC BY-NC-SA 4.0](LICENSE-DOCUMENTATION.md) |
| Project-generated app-icon source and compiled icon; retired project-generated menu image assets retained in history | [CC BY-NC-SA 4.0](LICENSE-DOCUMENTATION.md), to the extent the licensor controls applicable rights |
| Illustrative code snippets embedded in prose documentation | SUL-1.0, like the functional source they illustrate |
| Third-party dependencies, upstream material and license texts | Their respective upstream terms; no relicensing claim |
| Product names and trademarks | No trademark license is granted by this scope map |

SUL-1.0 permits personal/noncommercial use and use or modification for your own internal business purposes. Distribution or provision to others must be free of charge for noncommercial purposes; preserve notices and prominently identify modified copies. Read the actual license for the complete terms. It is not a blanket prohibition on all business use.

CC BY-NC-SA 4.0 permits sharing and adaptations subject to its attribution, NonCommercial and ShareAlike terms. The separate image/document scope also matters when packaging software for others; a software license alone does not override those content terms.

The same scope map covers project-original material in the reachable project history; no earlier repository license was found in the inspected history. This grant does not extend to private working files, browser data or local evidence outside the published tree. [Provenance](docs/PROVENANCE.md) records the observed material origins and limits.

There is no contributor copyright assignment. Contributions do not become maintainer-owned merely by being merged; any later contribution must preserve authorship and an applicable grant for its material scope.
