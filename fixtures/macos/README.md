# macOS fixtures

`phase0-corpus.json` contains synthetic, redacted process topology and arguments. Paths and identities are invented; no page content, credentials, live username, real repository path, port ownership, or browser profile identifier is present.

A fixture may prove a model invariant. It does not prove that a runtime/version signature is field-valid or safe for automatic cleanup. Real captures must be redacted outside the worktree before admission and paired with the nearest normal-process counterexample.
